PornLinkGenerator for macOS

This package contains the build script for macOS.

Important:
- This file must be run on a real macOS computer.
- Do not try to run it on Windows.

Files:
- build_macos.sh

Run:
1. Open Terminal on macOS.
2. chmod +x build_macos.sh
3. ./build_macos.sh
4. The output will be in dist/PornLinkGenerator.app
