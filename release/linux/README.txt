PornLinkGenerator for Linux

This package contains the build script for Linux.

Important:
- This file must be run on a real Linux computer.
- Do not try to run it on Windows.

Files:
- build_linux.sh

Run:
1. Open Terminal on Linux.
2. chmod +x build_linux.sh
3. ./build_linux.sh
4. The output will be in dist/PornLinkGenerator
